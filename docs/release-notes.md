# ACS FiservDNA Connector release notes

This page lists changes for each ACS FiservDNA Connector release. Each entry is prefixed with :eight_spoked_asterisk: and listed under **What's new** or **Fixes**.

## 25

### 25.0.3

2026 March

#### What's new

:eight_spoked_asterisk: **CON-928**: Display DNA QueueID in user interface. DNA QueueID remains in user interface when job completes.

:eight_spoked_asterisk: **CON-927**: Support Advanced Failure Criteria.

#### Fixes

:eight_spoked_asterisk: **CON-885**: Drive mapping user passwords must be re-encrypted so the Fiserv DNA connector can decrypt them.

:eight_spoked_asterisk: **CON-886**: Implement Event definitions in the user interface and add them to the generated .ini file.

:eight_spoked_asterisk: **CON-919**: Support environment variables.
